
# 🍕 Pizza Studio

A Windows Forms app (C# / .NET) where you build your own pizza and see the order summary and price update live.

Part of **Course 14** of Dr. Mohammed Abu-Hadhoud's roadmap (.NET with C#). I redesigned the interface with my own visual identity.

## Features

- Choose size, crust, toppings and service type (Eat In / Take Out)
- Live pizza preview that changes with the toppings
- Live order summary and total price
- Order and Reset buttons
- Cover screen with a Get Started button

## Built with

- C# and Windows Forms

## Run it

1. Clone the repo and open the `.sln` file in Visual Studio
2. Restore the NuGet packages
3. Press **F5**
